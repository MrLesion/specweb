# Project instructions

This project uses SpecWeb and OpenSpec.

Before planning or modifying code:

1. Read `.specweb/constitution.md`.
2. Read `.specweb/agents/workflow.md`.
3. Read the relevant documents under `.specweb/architecture/`.
4. Use the applicable skill under `.specweb/skills/`.
5. Inspect active OpenSpec artifacts under `openspec/changes/`.

Rules:

- Use vanilla JavaScript and native ES modules.
- Do not introduce a frontend framework.
- Treat `.specweb/constitution.md` as authoritative.
- OpenSpec describes change-specific requirements.
- `.specweb/` describes permanent implementation constraints.
- Do not modify architecture merely to simplify a feature implementation.
- Run the SpecWeb validation commands before completing work.
- For the OpenSpec + SpecWeb flow with examples, see `docs/specweb-openspec.md`.
